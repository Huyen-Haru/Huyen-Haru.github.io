01 · Bắt đầu

Giao diện và quy trình

Thanh trái có Report view để làm báo cáo, Data/Table view để xem dữ liệu đã nạp và Model view để quản lý quan hệ. Power Query Editor là cửa sổ làm sạch riêng.

Nhập dữ liệuHome → Get data → Excel/Text-CSV/SQL… → chọn bảng → Transform Data.
Làm sạchHome → Transform data để mở Power Query.
Tạo quan hệModel view → kéo khóa giữa hai bảng hoặc Manage relationships.
Làm biểu đồReport view → bấm vùng trống → chọn visual bên phải → kéo field vào.
Luồng chuẩn: câu hỏi → kiểm tra nguồn → Power Query → Model → DAX → Visual → kiểm thử → Publish.

03 · Power Query

Làm sạch có thể chạy lại

Mỗi thao tác được lưu trong Query Settings → Applied Steps và chạy lại khi Refresh.

Đổi kiểuChọn cột → Transform → Data Type.
Tách / gộp cộtTransform → Split Column hoặc Merge Columns.
Thêm dòng từ bảng khácHome → Append Queries (hai bảng cùng cấu trúc).
Ghép thêm cộtHome → Merge Queries → chọn khóa; thường dùng Left Outer.
Kiểm tra chất lượngView → Column quality, distribution, profile.
Bảng trung gianChuột phải query → bỏ Enable Load.
Đặt tên query và Applied Step rõ nghĩa. Không sửa tay file nguồn mỗi tháng nếu Power Query có thể tự động hóa.

05 · DAX

Column hay Measure?

Calculated column tính từng dòng và lưu trong model; dùng khi cần nhóm/lọc. Measure tính theo filter context; dùng cho KPI và tổng hợp.

Revenue = SUMX(Sales, Sales[Quantity] * Sales[UnitPrice] * (1-Sales[Discount]))
Cost = SUMX(Sales, Sales[Quantity] * RELATED(Products[UnitCost]))
Profit = [Revenue] - [Cost]
Margin % = DIVIDE([Profit], [Revenue])
Orders = DISTINCTCOUNT(Sales[OrderID])
Revenue YTD = TOTALYTD([Revenue], DimDate[Date])
Debug: đưa measure vào Table cùng dimension; xem từng dòng và Grand Total. Dùng VAR cho công thức dài.

07 · Dashboard

Bố cục dễ đọc

  1. Viết câu hỏi kinh doanh trước khi kéo visual.
  2. Canvas 16:9; View → Gridlines và Snap to grid.
  3. Trên: 3–5 KPI. Giữa: xu hướng/nguyên nhân. Dưới: chi tiết/hành động.
  4. Một màu chính, một màu cảnh báo, nền trung tính; khoảng cách nhất quán.
  5. Định dạng triệu/tỷ, %, ngày tháng nhất quán.
  6. Tiêu đề nên nói kết luận, không chỉ ghi tên biểu đồ.
Brief: Trong 30 giây, Giám đốc Nova Retail phải biết kết quả, xu hướng, vùng và sản phẩm cần chú ý. Tối đa 8 visual.
08 · Tương tác

Slicer, drill, tooltip, bookmark

SlicerInsert → Slicer → kéo field; Format → Slicer Settings chọn Dropdown/List/Tile/Between.
Sync slicerView → Sync slicers → chọn Sync/Visible từng trang.
Sửa tương tácChọn visual nguồn → Format → Edit interactions → Filter/Highlight/None.
Drill-downĐặt Year → Quarter → Month vào Axis → dùng mũi tên trên visual.
Drill-throughTrang chi tiết → kéo field vào Drill-through filters; giữ nút Back tự sinh.
Tooltip riêngTrang mới → Page Information: Tooltip On → Canvas: Tooltip → gán vào visual.
BookmarkView → Bookmarks + Selection → Add. Tắt Data nếu không muốn reset slicer.

  1. Revenue, Profit, Margin và Orders là bao nhiêu?
  2. Q1/2025 tăng hay giảm so với Q1/2024?
  3. Sản phẩm, vùng, kênh nào đóng góp nhiều nhất?
  4. Chiết khấu cao ảnh hưởng lợi nhuận thế nào?

Đầu ra

  • Star Schema, DimDate, ít nhất 8 measures.
  • Executive Overview ≤8 visual.
  • Product Detail có drill-through và tooltip.
  • PBIX, ảnh dashboard và case study một trang.
12 · Master tips

Thói quen của người làm tốt

  • Bắt đầu bằng câu hỏi, không bắt đầu bằng biểu đồ.
  • Đối soát tổng với nguồn trước khi trang trí.
  • Tách measures vào bảng “_Measures”, đặt tên và format rõ.
  • Dùng Performance Analyzer tìm visual/DAX chậm.
  • Cho người khác dùng thử mà không hướng dẫn.
  • Portfolio kể: vấn đề → dữ liệu → cách làm → insight → hành động.
