# Canva Từ Số 0

Website hướng dẫn người mới sử dụng Canva thành thạo qua 5 bài học:

1. Làm quen với Canva
2. Dùng mẫu và bố cục
3. Chữ, màu và hình ảnh
4. Video và hiệu ứng
5. Chia sẻ và xuất bản

Mỗi bài gồm hướng dẫn từng bước, phím tắt và thử thách thực hành. Trang tự lưu bài đã hoàn thành bằng `localStorage` trên trình duyệt.

## Chạy website

Mở file `index.html` bằng trình duyệt. Website không cần cài đặt hay build.
